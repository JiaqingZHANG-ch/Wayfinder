# Wayfinder

[Version française](README.fr.md)

给迷茫的年轻人用的 AI 成长导师：先弄清方向，再每天给一份马上能动手的计划，晚上对账，每周复盘。

它是一个通用模板，不针对哪一个人：课表、习惯、项目、作息、想去的方向，都由每个人在建档、设置和长谈里自己填。现在是本机单人版（网页 + 手机），还没有上线。

## 它会做什么

- **建档**：三分钟，问作息、课表、想坚持的习惯和手上的项目。
- **每天的计划**：排程求解器按课、通勤、三餐、精力和截止日排出逐时安排，做得到才给。下课后报一下电量，今晚的部分按电量重排，先看改了哪几处再决定要不要。
- **晚上对账**：一句话说今天做了什么，模型帮你记成每件事的完成情况，再定明天的一件事。
- **每周复盘**：一周做到了多少、哪里比预想少，提一条调整，你点「好」才生效。
- **深度长谈**：对完账后分四个晚上聊（现状、方向、能量、三个五年版本），智囊团从几个视角看你写的三个版本。聊出的使命、目标和一个月的小习惯，你确认了才写进档案，之后每天的计划里会写「为了：…」。
- **隐私**：数据都在本机；可以导出全部数据，也可以一键删除。说到伤害自己的话时，只给固定的求助话术和热线，不让模型自由发挥。

## 仓库里有什么

| 目录 | 是什么 |

| `src/`、`tests/` | 后端（FastAPI + SQLite）：导师、对账、复盘、智囊团、深度长谈 |

## 在自己电脑上跑起来

需要：[uv](https://docs.astral.sh/uv/)（管 Python）、Node.js 22 以上；想用本机模型的话再装 [Ollama](https://ollama.com/) 并 `ollama pull qwen3:14b`（大约 9 GB，16 GB 显存跑得动）。

Windows 上一键打开（Ollama、后端、网页版各开一个窗口，然后打开 <http://localhost:8081>）：

```powershell
.\wayfinder.ps1
```

也可以分开开：

```powershell
.\serve.ps1                       # 后端，http://127.0.0.1:8000/docs 能看到所有接口
.\web.ps1                         # 网页版，http://localhost:8081（第一次先在 mobile/ 里 npm install）
```

手机上用 Expo Go 打开见 `docs/backend.md`。

### 用哪个模型

启动前设环境变量 `MODEL`：

- `ollama`（`wayfinder.ps1` 的默认）：本机 qwen3:14b，说的话不离开这台电脑；
- `fake`（`serve.ps1` 的默认）：不用模型，一句话对账会改成让你点按钮，适合只看界面；
- `deepseek`：要先设 `DEEPSEEK_API_KEY`，你说的话会发给 DeepSeek。

## 数据

- 都存在 `var/app.db`（不进 git）。想从头再来，关掉后端后删掉这个文件。
- App 里「我」→「我的数据」可以导出全部数据或删除。
- 每样数据存在哪、存多久，见 `docs/data-inventory.md`。

## 智囊团的卡片

`src/mentor/cards/*.md` 里每张卡是一个视角，写着一位作者公开著作里的思考工具和出处。对用户显示时会注明：这是 AI 依据公开著作的模拟，不是本人的话。

- 改一个视角：直接改对应的文件，重启后端生效。
- 加一个视角：新建一个 `.md`，第一行 `# ××视角（源自某某）`，第二行 `领域：××`，其余照现有卡片写；每条原则都要有出处。
- 卡片里不要出现和伤害自己有关的字眼：视角的话里一出现，这次就停下来给求助话术（有测试检查）。
