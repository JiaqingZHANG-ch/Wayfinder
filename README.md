# Wayfinder

[Version française](README.fr.md)

给迷茫的年轻人用的 AI 成长导师：先弄清方向，再每天给一份马上能动手的计划，晚上对账，每周复盘。现在是本机单人版。

## 仓库里有什么

| 目录 | 是什么 |
|---|---|
| `src/`、`tests/` | 后端（FastAPI + SQLite）和导师、智囊团、深度长谈 |
| `mobile/` | App（Expo：网页版 + 手机） |
| `planner/` | 排程求解器（CP-SAT），原来的 daily-planner 仓库，历史都在；自己的说明见 `planner/README.md`（法语版 `planner/README.fr.md`） |
| `docs/` | 后端、界面、数据清单、设计和计划 |
| `supabase/` | 云端数据库迁移（还没在真库上跑过） |

## 启动 Wayfinder（现在用这个）

```powershell
.\wayfinder.ps1
```

一键开本机 Ollama、后端和网页版，并打开 <http://localhost:8081>。怎么用、改哪里见 `docs/backend.md`。

## 旧版（第一阶段第一步的单页导师）

```powershell
.\start.ps1
```

然后用浏览器打开 <http://127.0.0.1:8765>。需要环境变量 `DEEPSEEK_API_KEY`。

## 数据

- 全部存在 `var/mentor.db`（不进 git）。想从头再来，关掉程序后删掉这个文件即可。
- 你说的话会发给 DeepSeek 用来生成回复；除此之外不离开这台电脑。

## 代码

| 文件 | 负责什么 |
|---|---|
| `src/mentor/store.py` | 数据库：档案、对话、每日记录、每周复盘 |
| `src/mentor/safety.py` | 危机关键词检查与固定的求助话术 |
| `src/mentor/model.py` | DeepSeek 客户端 |
| `src/mentor/prompts.py` | 给模型的固定指示，以及每次带给它的档案和近期记录 |
| `src/mentor/mentor.py` | 判断这次聊什么、处理一轮对话、校验并保存结果 |
| `src/mentor/ui.py` | 对话、档案、记录三个页面 |

| `src/mentor/council.py` | 智囊团：几个视角各自独立看一个人的情况，再合成一个建议 |
| `src/mentor/cards/*.md` | 视角卡片，每张写着一位作者公开著作里的思考工具和出处 |

除 `ui.py` 外都不依赖界面，将来换成 App 可以原样留用。

## 智囊团与卡片

建档完成后、每周复盘开始时各开一次会，大约一分钟：每张卡片一个视角，互相看不到对方的意见，最后合成一个建议。

卡片分五个领域、每个领域两张。领域多于三个时先分诊：模型看这个人的情况，挑出最相关的 2–3 个领域，只请这些领域的视角发言。挑不出来就用排在最前的两个领域。

- 改一个视角：直接改 `src/mentor/cards/` 里对应的文件，重启生效。
- 加一个视角：新建一个 `.md`，第一行 `# ××视角（源自某某）`，第二行 `领域：××`，其余照现有卡片的结构写。
- 每条原则都要有出处。对用户显示时会注明这是 AI 依据公开著作的模拟，不是本人言论。
- 卡片里不要出现和伤害自己有关的字眼：视角的话里一出现这类字眼，当天的带练就会中断（有测试检查）。
- 知识库 `成长导师/智囊团卡片/` 里的是给人审阅的副本；这里的文件才是程序用的。
