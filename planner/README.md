# 排程求解器（planner）

🇫🇷 [Version française](README.fr.md) · 🇨🇳 中文说明（本页）

这是 Wayfinder 的排程引擎。它读入一个人一天的情况（课表、通勤班次、三餐、想坚持的习惯、手上的项目和截止日），用约束求解器（Google OR-Tools CP-SAT）排出一份**真人做得到**的逐时安排。所有规则都来自输入，不针对哪一个人：谁的课、谁的习惯、谁的作息，都由 Wayfinder 的建档和设置填进来。

## 它会照顾什么

1. **硬约束**：课和考试、睡觉、三餐、通勤。回家的车离下课至少留 20 分钟（可设），换地方前后留转场时间。
2. **每天要做的习惯**：每个习惯有时长和时间窗，可以规定只能在家做、可以在路上做、几个习惯连成一块做。排不下不会悄悄删掉，而是报错说明是什么挡住了。
3. **项目**：分剩下的时间。谁更急看的是**松弛时间**（截止前还能用的时间 − 还需要的时间），不只看截止日；一天的专注总量有上限，课多的日子少排项目。
4. **精力**：课、习惯、项目各有消耗，喜欢的事消耗少；当天报的电量低时，习惯只排保底版。
5. **只重排今天剩下的部分**：白天情况变了，已经过去的不动，只排之后的。

排完还会**独立检查一遍**：不重叠、每段通勤都有车、下课后时间够、只能在家做的事不会排在学校、睡够时间。不通过就不输出，并说明原因。

## 示例

`examples/2026-11-16.json` 是一位虚构的大学生的周一（专业课、期中考试、下午实验课）。实际排出来是：

```
06:30 早饭 → 07:11 出门（路上听英语）
08:00 专业课 → 10:15 期中考试 → 12:15 午饭
13:00–15:30 自由时间
15:30 实验课 → 17:51 坐车回家 → 18:21 晚饭
19:06 写日记 → 20:06 看书 → 20:36 拉伸
```

它选 17:51 的车，不选 17:35 那班，因为离下课太近；这一天课和考试已经用掉大半精力，所以晚上不再排项目，并给出提示。`examples/users/` 里还有几个虚构用户的完整设置。

## 运行

```powershell
.\run.ps1 examples\2026-11-16.json -o out.json
```

测试：`uv run pytest`（84 项）

输入格式见 `src/planner/model.py`，规则清单和来历见 `docs/constraints.md`。

## 数据和隐私

真实数据只放 `data/`（已在 `.gitignore` 里），不进仓库。`examples/` 里只有虚构的人。
