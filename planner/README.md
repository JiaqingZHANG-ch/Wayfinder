# 每日规划师（daily-planner）

🇫🇷 [Version française](README.fr.md) · 🇨🇳 中文说明（本页）

把一天的课表、公交班次、必做习惯和项目任务交给约束求解器（Google OR-Tools CP-SAT），排出一份真人做得到的逐时安排。

- **硬约束**：课、考试、睡觉、三餐、通勤；回家的车离下课至少 20 分钟，换地方前后留转场。
- **必做四样**：练字、看书、英语、法语，时长固定，排不下就报错说明原因。
- **项目**：按松弛时间（截止前还能用的时间 − 还需要的时间）决定谁更急；每天专注总量有上限；做不完会报警。
- **自检**：排完再独立检查一遍，不通过就不输出。

设计文档在作者的笔记库里（`每日规划师/2026-11-16｜设计｜每日规划师.md`）。这是第一步：只排一天。

## 运行

```powershell
.\run.ps1 examples\2026-11-16.json -o out.json
```

测试：`uv run pytest`

## 数据和隐私

真实数据只放 `data/`（已在 `.gitignore` 里），不进仓库。`examples/` 里是去掉个人信息的示例。
