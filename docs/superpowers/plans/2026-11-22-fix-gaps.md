# 修补缺口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 每块点「开始」才计时（晚开始按打断处理）、「做完了」5 秒内可撤销、「明天的一件事」排满时不被挤掉、说的事能改标题。

**Architecture:** 后端新加 `POST /block/{id}/start`，晚开始复用 `runs.extend`（和「继续」同一套往后推 / 问重排）；pause / resume 要求先开始；`run_reminders` 只给开始过的块发番茄提醒。App 的 `pickNow` 改优先级，NowCard 加「开始」和 5 秒撤销。`day_raw` 给 one-thing 加 `must_today`。`/plan/edit` 加可选 `title`。

**Tech Stack:** FastAPI + SQLite（`src/server/`），Expo SDK 58（`mobile/`），pytest，`node --experimental-strip-types` 自检脚本。

**Spec:** `docs/superpowers/specs/2026-11-22-fix-gaps-design.md`

## Global Constraints

- 小打断阈值照旧 `SMALL_BREAK = 15`，往后推按 5 分钟向上取整（`-(-g // 5) * 5`）。
- 文案不催人：只写事实（「14:00 该写报告了」），不写「迟到」「落后」。
- 状态行「还没开始」：`{start}–{end} · 还没开始`。撤销条：「记为做完了 · 撤销」，5 秒。
- 改标题：去掉首尾空白 1–30 字；只能改当天说的事；习惯 / 项目 422「习惯和项目的名字在设置里改」。
- 今天页重排后被挤掉的写「今天排不下了」；晚上报电量页照旧「今晚不排了」。
- 不推送、不合并；每个任务单独提交，提交信息中文，带 Co-Authored-By 行。

## Review Focus

1. 过了块的计划结束才点「开始」（卡片不会显示，但接口能被调）→ 409，不能存出 start ≥ end 的块。
2. 准点开始（同一分钟）→ 只记录，不存新版本。
3. 晚开始超过 15 分钟、后面撞课 → `ask_reflow` 为真、`overlaps` 有值，块的 start 是现在。
4. 撤销后刷新 / 重进今天页 → 这一块没被记成做完。
5. 改标题带危机字眼 → 返回危机话术，计划和事项都不改。

每条的测试写在下面对应任务里（1–3、5 在后端测试，4 在浏览器实测）。
