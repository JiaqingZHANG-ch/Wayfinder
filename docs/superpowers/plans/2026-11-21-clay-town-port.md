# 黏土小镇搬进 App · 实施计划

**目标**：把用户选定的「黏土小镇」v4 小样，搬进 Expo App 的「今天」「本周」「我」三页，以及报电量、对账两个流程。只换皮，数据和接口用 App 现有的，不改后端，也不改求解器。

**架构**：
- 先换 `mobile/src/theme.ts` 的令牌和 `components/ui.tsx` 的基础件（卡片、按钮、标签栏）。这一步做完，其他页面会自动换成新皮。
- 再新增一个黏土舞台组件：场景、石子、分层小人、导师气泡。
- 三页和两个流程逐个接上。

**技术栈**：Expo SDK 58、React Native 0.88、reanimated 4、gesture-handler、expo-image。新增 `@expo-google-fonts/nunito`。

**规格**（本地文件，不进仓库，执行者自己去读）：
- 视觉和交互：`.oil-ui/redesign2/explore/A-clay-town-v4.html`，顶部注释里有材质规范，`:root` 里有令牌。
- 截图：`.oil-ui/redesign2/shots/A4/`。
- 剩下的毛病：`.oil-ui/redesign2/reviews/A-r4.md`，在任务 5 里修。
- 产品事实：`.oil-ui/redesign/facts.md`。

## 全局约束
- 材质只有两种说法：
  - 黏土 = 图片，用 `assets/images/clay/` 里的 webp；
  - 控件 = 平色块，不描边，不叠模糊投影，厚度只靠一道实色底边 `0 4px 0 <edge>`。在 RN 里用一个 4px 的底层 View 或 `boxShadow` 实现。
- 颜色照 v4 的 `:root`，白天一套，夜里一套。App 的深色模式就是 v4 的夜间配色。对比度要求：文字 ≥ 4.5:1，非文字 ≥ 3:1。改了颜色要重新核对，并在 theme.ts 的注释里写上实测值。
- 字体：数字和英文用 Nunito 700/800/900，中文用系统字体。
- 不打分、不催、没有连胜、不用刺眼的红色。文案要短，像人说话（用户原话：「信息太密集、AI 味太重」）。
- 每屏只留必要的信息，不加 v4 里没有的标签和说明。
- 「减少动态效果」打开时，常驻动效（呼吸、眨眼）停掉，手势松手后直接落位。
- 不改 `backend/`、`planner/`，也不改接口类型。
- 每个任务做完都要跑这三项，全部通过才能提交：
  - `cd mobile && npx tsc --noEmit`
  - `npx expo lint --no-cache`
  - `git diff --check`
- 每个任务单独提交到 `clay-town` 分支。不推送，不合并。
- 素材授权：千问 2.1 只许非商用。素材可以先进分支，上架前要重新出图，见 `assets/images/clay/LICENSE-NOTE.md`。

## 任务 1 · 令牌、字体、素材、基础件
- 把 v4 实际引用的 `A4-*` 素材（还有 v4 引用到的少量 A2 / A3 素材）复制到 `mobile/assets/images/clay/`，去掉 `A4-` 前缀。同目录写 `LICENSE-NOTE.md`，三行说明：来源、模型、授权限制。
- `theme.ts`：
  - light / dark 换成 v4 的令牌：bg、surface、surface-2、tint、ink、ink-2、primary、primary-edge、on-primary、primary-ink、done、mark、line、card-edge；
  - 圆角改成 card 20、btn 14、in 12；
  - 数字字体换成 Nunito。
  - 旧令牌名还有页面在用的话，映射到新值，不要删名字导致编译错误。
- `ui.tsx`：
  - Card：平色块 + 卡片内高光 + 4px 实色底边；
  - Button：主色黄 + primary-edge 底边，按下时底边收到 0、整体下移 4px；
  - Chip、ListRow 统一用这套做法。
- 标签栏 `(tabs)/_layout.tsx`：平色块 + 底边，选中项用浅主色底。
- 验收：三项检查都通过；Expo web 打开今天、本周、我三页，不报错，都已经换成奶油底和黄色主色。

## 任务 2 · 黏土舞台和今天页
- 新建 `components/clay.tsx`：
  - `Stage`：300 高；白天和夜里两张场景交叉淡入；石子数等于还没做的事，做完一件就淡出一颗；
  - `Figure`：身体、头、闭眼、表情、影子分层叠放；常驻有呼吸（4s，1 → 1.014）和眨眼（120ms）；姿势和表情按电量 1–5 切换；
  - `Bubble`：导师的一句话。
- `(tabs)/index.tsx` 今天页照 v4 排：
  - 舞台；
  - 「现在 · 事名」加上「还剩 N 分钟」大数字；
  - 「接下来」列表：每行左边是时间、黏土图标和标题，下面一行副标题。被重排改过的行用 tint 底色，副标题写「10 分钟 · 原 30」。
- 事件图标的映射写成一个小函数：按 kind 和标题关键词，选 class / eng / read / gym / proj / lunch / sleep；匹配不到就按 kind 兜底。
- 验收：今天页在白天、夜里都和 v4 截图一致。

## 任务 3 · 报电量、对账
- **报电量**：舞台右侧放电池。
  - 点一下展开 5 档阶梯，每档配一个词：1 只想躺着、2 有点累、3 正常、4 不错、5 很有劲。按住上下拖动来选档，带触感反馈。
  - 位移 < 8px 不算提交。松手后调用 App 现有的报电量接口（和 `energy.tsx` 用同一个），小人的表情跟着换，改动的行变色。
  - 原来的 `energy.tsx` 路由保留，作为兜底入口。
- **对账**：19:00 以后主按钮变成「对个账」，打开 `checkin.tsx`，照 v4 改样式：
  - 顶上是托盘格，可以点回去改；
  - 中间一张大卡，配事件图标；
  - 下面三个按钮：做了、做了保底、今天没做；
  - 白天被挪走的事不进对账。
- **收尾**：写完以后显示坐在山坡上的小人，配文「今天收住了」和挪走的事的一句话，按钮写「晚安」。
- 验收：在 web 上走通「报 2 格 → 列表改动」和「对完 3 件 → 收尾」两条路。

## 任务 4 · 本周、我
- **本周**：
  - 顶上一条夜豆，表示这 7 晚哪几晚记了，这一条并进记号表的第一行；
  - 每个习惯一行，用实心、半实心、空心、短线四种记号；
  - 项目的估时对比用石子堆表示；
  - 复盘入口照 v4。
- **我**：舞台上站一个微笑的小人，下面是「我的方向」、长谈进度和主按钮、我的记号、设置行。
- 滚动区从状态栏下面开始，不能和状态栏的字重叠。
- 验收：两页的白天和夜里都和 v4 截图一致。
