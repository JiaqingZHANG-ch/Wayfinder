# 约束清单

规划器排一天时要守的每一条规则都登记在这里。加新约束的流程：
1. 先在表里加一行，状态写「以后」。
2. 做到时改成「这一步做」，补上测试。
3. 做完改成「已实现」。

「在哪」一列的意思：
- 求解器：`src/planner/` 里的代码。
- 日程助手：每天早上的自动排程和日历同步，不在这个仓库里。
