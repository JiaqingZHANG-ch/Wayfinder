# Wayfinder 界面设计规范

## 理念：有点温度的陪伴者，长得像一块安静的仪表

Wayfinder 每天陪你排计划、晚上对账、每周复盘。它不是效率工具，也不是监工。视觉方向叫「安静的仪表」：高级感来自大号细字重的数字、克制的颜色和「看得见的重排」，不靠背景特效。所以界面要：

- **柔和**：暖纸色底、陶土色强调色，不用纯白和纯黑，不用刺眼的红。
- **圆润**：卡片圆角 24，按钮和选项是胶囊形。
- **安静**：一屏只有一件主要的事、一个最大的数字、一处实心陶土色；吃饭、路上、自由时间这类「生活块」画得更淡更小。
- **昼夜**：白天暖纸色，21:00–6:00 一律暖炭色（系统是深色时全天深色）。
- **说人话**：问候语跟着时间变（早上好／晚上好／夜深了），提示用「可不填」「不写也行」，不打分、不催。

调研依据见知识库 `17-AI学习/AI应用开发与FDE实战/AI从0开发/成长导师/调研/reports/`：`界面设计调研.md`、`高级视觉风格调研.md`、`Fable用户视角评审.md`，三个方向的对比稿是 `wayfinder-styles.html`。

## 令牌（`mobile/src/theme.ts`）

页面里**不直接写颜色和数字**，都从 `theme.ts` 拿：`useColors()` 给当前配色（白天跟随系统，夜里深色；`useDark()` 只问是不是深色），`space`、`radius`、`type` 是固定值。

| 用途 | 浅色 | 深色 |
|---|---|---|
| 页面底 `bg` | `#FAF6F0` | `#1C1916` |
| 卡片 `card` | `#FFFDF9` | `#26221E` |
| 输入框 / 未选中 `sunken` | `#F3ECE2` | `#302A25` |
| 正文 `text` | `#2E2A26` | `#F2ECE4` |
| 次要字 `muted` | `#6E655C` | `#B3A99E` |
| 强调 `primary`（陶土色） | `#B4573A` | `#E3906F` |
| 选中底 `soft` / 字 `onSoft` | `#F6E3D9` / `#8A3F27` | `#4A3027` / `#F3C9B6` |

计划里每类事情一个颜色（`kind`）：课 灰褐、习惯 鼠尾草绿、项目 雾蓝、可选 麦黄、生活 淡灰褐（小一号的点，比线条深一点，看得见但不抢眼）。

- 间距 `space`：4 / 8 / 12 / 16 / 24 / 32。
- 圆角 `radius`：10 / 16 / 24 / 胶囊。
- 字号 `type`：阶梯 12 / 14 / 16 / 20 / 28 / 44 / 64，字重只用 400 / 500 / 600。small 12、label 14、body 16、title 20、display 28；数字用 Geist（`@expo-google-fonts/geist`，根布局里加载）：`hero` 64 细体（一屏最多一个）、`big` 44 细体、`stat` 28、`num`（叠在别的字号上给时间和计数用）。中文仍用系统字体。
- 表面：卡片实色加发丝边（`edge`），投影几乎看不见；「此刻」主卡片用 `glow`（浅色是一层软投影，深色是一圈陶土微光）。玻璃（`glass` / `glassEdge` / `glassShadow`）只给控制层。

## 组件（`mobile/src/components/ui.tsx`）

页面只拼这些：`Screen`、`Card`（可点、可带入场顺序 `i`）、`Stat`（数字瓷砖：小标题、一个数加单位、一句话）、`Glass`（iOS 26 用系统液态玻璃，其余是半透明底加发丝边、网页加背景模糊）、`Display` / `Title` / `Body` / `Label` / `Small` / `Eyebrow`、`Button`（primary / secondary / quiet / danger，可带图标）、`IconButton`、`Chip`、`Row`、`ListRow`、`Field`、`Notice`、`CrisisCard`、`Loading`、`Icon`（Ionicons）。

动效和触感在 `mobile/src/components/motion.tsx`：`Pressy`（按下缩放）、`enter(i)`（错峰入场）、`Skeleton`、`Bar`（进度条）、`haptic`。底部面板是 `mobile/src/components/sheet.tsx`。计划时间线是 `PlanView`（给 `now` 时过去的块变淡、正在做的高亮、空档画「现在」线；再给 `fold` 就把过去的块收成「早些时候 · N 件」）。报电量前后的对比在 `mobile/src/diff.ts`，自检：`cd mobile && node --experimental-strip-types scripts/diff-check.mjs`。

玻璃只用在底部标签栏和底部面板（Apple 的规矩：玻璃是控制层，内容层不用）。不做漂浮光斑、不做全屏渐变。

新页面需要的样式这里没有时，先加到 `ui.tsx` 或 `theme.ts`，再在页面里用。

## 规则

1. **对比度**：每对「字 / 底」≥ 4.5:1（WCAG AA）。改色后要重新算，`theme.ts` 注释里记了每对的值。
2. **可点区域**：至少 44pt（`Chip` 44、`Button` 48）。
3. **读屏**：`Button`、`Chip`、首页入口块都有 `accessibilityLabel`；单选用 `radio`，多选用 `checkbox`。
4. **字体**：中文只用系统字体，不打包中文字体；数字和英文用 Geist。中文正文行高约 1.6 倍，标题 1.3–1.4 倍；不用斜体，不加字距。
5. **危机提示**：用平静的普通卡片（`CrisisCard`），不用红色、不弹窗。
6. **出错**：红字只用于真的出错；「今天已经过完了」这类状态说明用普通提示。
7. **网页**：内容最宽 560，居中，像一张纸。网页用单页模式（`app.json` 的 `web.output: "single"`），不在服务器上先渲染，这样深色模式不会出现浅色标题栏。
8. **改动画值**用 `.set()`，不直接给 `.value` 赋值（React 编译器的检查要求）。

## 交互

调研依据：知识库 `成长导师/调研/reports/交互设计调研.md`。

**导航**：底部浮动标签栏，三个标签「今天 / 本周 / 我」。报电量是从底部弹出的面板（透明弹层，后面看得见今天）；晚间对账是全屏流程；复盘、设置、数据、建档从标签页推进去，带返回。从提醒直接点进 `/energy`、`/checkin` 时，下面也会先垫一层标签页（`unstable_settings.initialRouteName`）。

**今天**：问候 →「此刻」主卡片（最大的是一个数：还剩几分钟 / 离下一件几分钟 / 还有几件等对账）→ 唯一的实心按钮（19:00 前是「下课了，报个电量」，之后或者今天的事都过完了是「对个账」；另一个入口是下面一行淡色文字，今天过完了就不再给报电量）→ 两块数字瓷砖（电量几格、这 7 天记了几天）→ 复盘入口 → 时间线（只显示接下来，过去的折叠）。可以下拉刷新；每次回到这页都重新拿计划。

**报电量**：五格电池，点哪格就亮到哪格（1–2 格琥珀色，3 格以上绿色）→ 立刻列出「今晚这样排（改了 N 处）」：时长变了的划掉原来的（看书 45 分 → 15 分），还有挪了时间、今晚不排了、新加的；下面是今晚完整的安排 → 点「就这样」确认后面板收起。点遮罩、点关闭、按住顶部往下拉都能关。

**晚间对账**：一屏一问。每件事一屏，三个大选项（做了 / 做了保底 / 今天没做），点完停 0.3 秒自动翻页；项目再问一句和预想比；然后是「想说点什么」和「明天最想先做的一件事」。顶部有进度条，左上角回上一步，右上角可以改成一句话说完。完成页：对勾弹出，原样引用你写的那句话，再加 7 天记录点；填了「明天的一件事」就把它念回来。不做连胜，不做惩罚。

**本周**：Bento 瓷砖，每块一个数一句话：记了几天（大号 N / 7 加 7 格日条）、每个习惯做了几天、每个项目「比预想少 / 差不多 / 多」各几次（直接写数，不用颜色图例）、复盘入口。

**动效**：按下时缩到 0.97，弹簧回弹；列表错峰入场，每个晚 45ms，最多错开 8 个；进度条出现时从 0 长到目标值；面板用弹簧滑入。系统开了「减少动态效果」时，reanimated 会自动跳过动画。

**触感**：只用在三处：选了一个选项（selection）、确认计划和完成对账（success）。网页上没有触感。

**加载**：读数据时用骨架屏（灰块轻轻呼吸），不用一行「正在加载」。
