# Wayfinder 界面设计规范

## 理念：有点温度的陪伴者

Wayfinder 每天陪你排计划、晚上对账、每周复盘。它不是效率工具，也不是监工，所以界面要：

- **柔和**：暖纸色底、陶土色强调色，不用纯白和纯黑，不用刺眼的红。
- **圆润**：卡片圆角 24，按钮和选项是胶囊形。
- **安静**：一屏只有一件主要的事；吃饭、路上、自由时间这类「生活块」画得更淡更小。
- **说人话**：问候语跟着时间变（早上好／晚上好／夜深了），提示用「可不填」「不写也行」，不打分、不催。

调研依据见知识库 `17-AI学习/AI应用开发与FDE实战/AI从0开发/成长导师/调研/reports/界面设计调研.md`。

## 令牌（`mobile/src/theme.ts`）

页面里**不直接写颜色和数字**，都从 `theme.ts` 拿：`useColors()` 给当前配色（跟随系统浅色 / 深色），`space`、`radius`、`type` 是固定值。

| 用途 | 浅色 | 深色 |
|---|---|---|
| 页面底 `bg` | `#FAF6F0` | `#1C1916` |
| 卡片 `card` | `#FFFDF9` | `#26221E` |
| 输入框 / 未选中 `sunken` | `#F3ECE2` | `#302A25` |
| 正文 `text` | `#2E2A26` | `#F2ECE4` |
| 次要字 `muted` | `#6E655C` | `#B3A99E` |
| 强调 `primary`（陶土色） | `#B4573A` | `#E3906F` |
| 选中底 `soft` / 字 `onSoft` | `#F6E3D9` / `#8A3F27` | `#4A3027` / `#F3C9B6` |

计划里每类事情一个颜色（`kind`）：课 灰褐、习惯 鼠尾草绿、项目 雾蓝、可选 麦黄、生活 淡灰褐（小一号的点，比线条深一点，看得见但不抢眼）。

- 间距 `space`：4 / 8 / 12 / 16 / 24 / 32。
- 圆角 `radius`：10 / 16 / 24 / 胶囊。
- 字号 `type`：display 28、title 20、body 16、label 15、small 13。

## 组件（`mobile/src/components/ui.tsx`）

页面只拼这些：`Screen`、`Card`（可点、可带入场顺序 `i`）、`Display` / `Title` / `Body` / `Label` / `Small` / `Eyebrow`、`Button`（primary / secondary / quiet / danger，可带图标）、`IconButton`、`Chip`、`Row`、`ListRow`、`Field`、`Notice`、`CrisisCard`、`Loading`、`Icon`（Ionicons）。

动效和触感在 `mobile/src/components/motion.tsx`：`Pressy`（按下缩放）、`enter(i)`（错峰入场）、`Skeleton`、`Ring`（进度环）、`Bar`（进度条）、`haptic`。底部面板是 `mobile/src/components/sheet.tsx`。计划时间线是 `PlanView`（给 `now` 时过去的块变淡、正在做的高亮、空档画「现在」线）。

卡片在浅色里靠柔和投影（`shadow`），深色里投影看不见，改用细边（`edge`）。

新页面需要的样式这里没有时，先加到 `ui.tsx` 或 `theme.ts`，再在页面里用。

## 规则

1. **对比度**：每对「字 / 底」≥ 4.5:1（WCAG AA）。改色后要重新算，`theme.ts` 注释里记了每对的值。
2. **可点区域**：至少 44pt（`Chip` 44、`Button` 48）。
3. **读屏**：`Button`、`Chip`、首页入口块都有 `accessibilityLabel`；单选用 `radio`，多选用 `checkbox`。
4. **字体**：只用系统字体，不打包中文字体。中文正文行高约 1.6 倍，标题 1.3–1.4 倍；不用斜体，不加字距。
5. **危机提示**：用平静的普通卡片（`CrisisCard`），不用红色、不弹窗。
6. **出错**：红字只用于真的出错；「今天已经过完了」这类状态说明用普通提示。
7. **网页**：内容最宽 560，居中，像一张纸。网页用单页模式（`app.json` 的 `web.output: "single"`），不在服务器上先渲染，这样深色模式不会出现浅色标题栏。
8. **改动画值**用 `.set()`，不直接给 `.value` 赋值（React 编译器的检查要求）。

## 交互

调研依据：知识库 `成长导师/调研/reports/交互设计调研.md`。

**导航**：底部浮动标签栏，三个标签「今天 / 本周 / 我」。报电量是从底部弹出的面板（透明弹层，后面看得见今天）；晚间对账是全屏流程；复盘、设置、数据、建档从标签页推进去，带返回。从提醒直接点进 `/energy`、`/checkin` 时，下面也会先垫一层标签页（`unstable_settings.initialRouteName`）。

**今天**：问候 →「此刻」主卡片（正在做的事、还剩多久、进度、下一件；空档时显示下一件；都过完了就提醒对账）→ 两个入口（19:00 前突出「下课了」，之后突出「晚间对账」）→ 精力环和 7 天记录点 → 复盘入口 → 时间线。可以下拉刷新；每次回到这页都重新拿计划。

**报电量**：五格电池，点哪格就亮到哪格（1–2 格琥珀色，3 格以上绿色）→ 立刻给出「今晚这样排」→ 点「就这样」确认后面板收起。点遮罩、点关闭、按住顶部往下拉都能关。

**晚间对账**：一屏一问。每件事一屏，三个大选项（做了 / 做了保底 / 今天没做），点完停 0.3 秒自动翻页；项目再问一句和预想比；然后是「想说点什么」和「明天最想先做的一件事」。顶部有进度条，左上角回上一步，右上角可以改成一句话说完。完成页：对勾弹出，原样引用你写的那句话，再加 7 天记录点。不做连胜，不做惩罚。

**本周**：记录环（N / 7 天）、复盘入口、每个习惯一条进度条、项目的「比预想少 / 差不多 / 多」分段条。

**动效**：按下时缩到 0.97，弹簧回弹；列表错峰入场，每个晚 45ms，最多错开 8 个；进度环和进度条出现时从 0 长到目标值；面板用弹簧滑入。系统开了「减少动态效果」时，reanimated 会自动跳过动画。

**触感**：只用在三处：选了一个选项（selection）、确认计划和完成对账（success）。网页上没有触感。

**加载**：读数据时用骨架屏（灰块轻轻呼吸），不用一行「正在加载」。
