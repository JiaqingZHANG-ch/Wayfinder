# Wayfinder 界面设计规范

## 理念：找路的人看天色

Wayfinder 每天陪你排计划、晚上对账、每周复盘。它不是效率工具，也不是监工。

2026-11-21 起视觉方向叫「天色」：对标了 Tiimo、Structured、Rise、Gentler Streak、Oura、How We Feel 的真实截图（`商业级界面对标调研.md`），发现商业级 App 都有一个看一眼就认得的招牌画面，而我们只有一摞圆角卡片。所以有三样招牌（`mobile/src/components/art.tsx`）：

1. **天色**（`Sky`）：三个标签页和对账背后，顶上约 460pt 是一片渐变天色，往下淡进底色，右上角一团柔光。清晨淡青、白天雾蓝、傍晚陶土粉、夜里靛紫（`skyTone()`）。跟着内容滚走（画在 ScrollView 内容里），卡片后面是干净的底。
2. **今天的弧**（`Arc`）：首页主角。一道像太阳走过天空的弧，从今天第一件事画到最后一件，走过的那段亮，每件正事一个记号，现在是一个发光的小点；弧里是衬线大数字。对完账整道弧亮着，弧下一个月亮。
3. **每件事的记号**（`Glyph`）：由名字算出 8 种几何形之一（「昨晚定的一件事」固定四角星），颜色按种类。时间线节点、对账每屏标题和三个选项、本周每行，都用这件事自己的记号；做了实心、保底左半实心、没做描边、没记一个小点。

数字用 Instrument Serif（`type.hero / big / stat`），小标签用加字距的 `type.eyebrow`，卡片不描边（极淡的上亮下淡渐变加顶边一道高光）。中文标题 `display` / `title` 用 500，靠字号和留白分层，不靠加粗。

2026-11-21 Fable 第 6 轮（对标 6 款商业 App，6.5 分）之后又改了一轮：
- 天色三段（`top → mid → bg`），白天是雾蓝的天加同色相的亮蓝光团（和界面的陶土色要有色相差；金叠在蓝上会变卡其），光团跟着时间从左往右走，只在右边（x 60%–88%）。
- 首页页头是眉标「日期 · 问候」加一句结论（「还有 2 件事，23:30 收尾」），一屏只有一个 28 号：正在做的事。
- 弧下一层渐变光、走过的线是 3px 拖尾、记号 16px 坐在同色淡圆上、两脚标起止时间；对完账弧上的记号按对账结果画。
- 首页主按钮不通栏（`Button hug`）；全屏流程底部的按钮仍然通栏。
- 时间线：记号坐进 32 的同色淡圆（正在做的是陶土色实心圆），脊线 2px、过去的一段是淡陶土色，行高跟时长走（56–96）。
- 本周：七个星期和每个习惯一行 28px 的记号并成一张通栏的图，直接画在天色上。
- 对账：每屏中间一个 144 的大记号，后面一团同色柔光、上面一层高光；完成页是今晚对过的事的记号一排。
- 「我」页头下一排「我的记号」。

其余照旧：

- **柔和**：暖纸色底、陶土色强调色，不用纯白和纯黑，不用刺眼的红。
- **圆润**：卡片圆角 24，按钮和选项是胶囊形。
- **安静**：一屏只有一件主要的事、一个最大的数字、一处实心陶土色；吃饭、路上、自由时间这类「生活块」画得更淡更小。
- **昼夜**：白天暖纸色，21:00–6:00 一律暖炭色（系统是深色时全天深色）。
- **说人话**：问候语跟着时间变（早上好／晚上好／夜深了），提示用「可不填」「不写也行」，不打分、不催。

调研依据见知识库 `17-AI学习/AI应用开发与FDE实战/AI从0开发/成长导师/调研/reports/`：`界面设计调研.md`、`高级视觉风格调研.md`、`Fable用户视角评审.md`，三个方向的对比稿是 `wayfinder-styles.html`。

## 令牌（`mobile/src/theme.ts`）

页面里**不直接写颜色和数字**，都从 `theme.ts` 拿：`useColors()` 给当前配色（白天跟随系统，夜里深色；`useDark()` 只问是不是深色），`space`、`radius`、`type` 是固定值。

| 用途 | 浅色 | 深色 |
|---|---|---|
| 页面底 `bg` | `#FAF6F0` | `#141211` |
| 内容卡片 `surface`（微透） | `rgba(255,253,249,.82)` | `rgba(255,240,225,.055)` |
| 实色面板 `card`（底部面板、保存栏） | `#FFFDF9` | `#221E1B` |
| 输入框 / 未选中 `sunken` | `#F3ECE2` | `rgba(255,240,225,.08)` |
| 正文 `text` | `#2E2A26` | `#F2ECE4` |
| 次要字 `muted` | `#6E655C` | `#B3A99E` |
| 强调 `primary`（陶土色） | `#B4573A` | `#E3906F` |
| 选中底 `soft` / 字 `onSoft` | `#F6E3D9` / `#8A3F27` | `#4A3027` / `#F3C9B6` |

计划里每类事情一个颜色（`kind`）：课 灰褐、习惯 鼠尾草绿、项目 雾蓝、可选 麦黄、生活 淡灰褐（小一号的点，比线条深一点，看得见但不抢眼）。

- 间距 `space`：4 / 8 / 12 / 16 / 24 / 32。
- 圆角 `radius`：10 / 16 / 24 / 胶囊。
- 字号 `type`：阶梯 12 / 14 / 16 / 20 / 28 / 44 / 64，字重只用 400 / 500 / 600。small 12、label 14、body 16、title 20、display 28；数字用 Geist（`@expo-google-fonts/geist`，根布局里加载）：`hero` 64 细体（一屏最多一个）、`big` 44 细体、`stat` 28、`num`（叠在别的字号上给时间和计数用）。中文仍用系统字体。
- 表面：卡片实色加发丝边（`edge`），投影几乎看不见；「此刻」主卡片用 `glow`（浅色是一层软投影，深色是一圈陶土微光）。玻璃（`glass` / `glassEdge` / `glassShadow`）只给控制层。

## 组件（`mobile/src/components/ui.tsx`）

页面只拼这些：`Screen`、`Card`（可点、可带入场顺序 `i`）、`Stat`（数字瓷砖：小标题、一个数加单位、一句话）、`Header`（返回加标题，推进去的页面都用它）、`ErrorState`（没连上：图标、一句话、「再试一次」；原始报错不给用户看）、`Glass`（iOS 26 用系统液态玻璃，其余是半透明底加发丝边、网页加背景模糊）、`Display` / `Title` / `Body` / `Label` / `Small` / `Eyebrow`（卡片和区块顶上的小标签都用 `type.eyebrow`）、`Button`（primary / secondary / quiet / neutral / quietDanger / danger，可带图标；不能点时换成凹底灰字，不靠变透明）、`IconButton`、`Chip`（单选选中只换底和边，不加勾，免得变宽整排跳；多选给勾留固定位置）、`Row`、`ListRow`（图标块凹底灰图标）、`Field`、`PickField`（时间和日期：iOS 用系统小胶囊，Android 弹系统选择器，网页用浏览器自带的输入框）、`Num` 和 `HALF`（`fields.tsx`，数字框和半宽，设置和建档共用）、`Notice`、`CrisisCard`、`Loading`、`Icon`（Ionicons）。

动效和触感在 `mobile/src/components/motion.tsx`：`Pressy`（按下缩放）、`enter(i)`（错峰入场）、`from(动画, 起始值)`（改入场起始值；网页上跳过，见规则 9）、`ahead(方向)`（一屏一问的翻页，对账和复盘共用）、`Skeleton`、`Bar`（进度条，可给 `duration`）、`haptic`。底部面板是 `mobile/src/components/sheet.tsx`。计划时间线是 `PlanView`（给 `now` 时过去的块变淡、正在做的高亮、空档画「现在」线；再给 `fold` 就把过去的块收成「早些时候 · N 件」；`title` 是卡片顶上的小标题）。报电量前后的对比在 `mobile/src/diff.ts`，自检：`cd mobile && node --experimental-strip-types scripts/diff-check.mjs`。

玻璃只用在底部标签栏和底部面板（Apple 的规矩：玻璃是控制层，内容层不用）。渐变只用在三处：天色（页面顶上、不动）、主按钮（两段陶土色加顶边高光和同色投影，`primaryGrad` / `primaryShadow`）、卡片表面（上亮下淡，`surfaceGrad`）。不做漂浮光斑。

新页面需要的样式这里没有时，先加到 `ui.tsx` 或 `theme.ts`，再在页面里用。

## 规则

1. **对比度**：每对「字 / 底」≥ 4.5:1（WCAG AA）。改色后要重新算，`theme.ts` 注释里记了每对的值。
2. **可点区域**：至少 44pt（`Chip` 44、`Button` 48）。
3. **读屏**：`Button`、`Chip`、首页入口块都有 `accessibilityLabel`；单选用 `radio`，多选用 `checkbox`。
4. **字体**：中文只用系统字体，不打包中文字体；大数字用 Instrument Serif，时间和小数字用 Geist。中文正文行高约 1.6 倍，标题 1.3–1.4 倍；不用斜体；只有眉标（`type.eyebrow`）加字距。
5. **危机提示**：用平静的普通卡片（`CrisisCard`），不用红色、不弹窗。
6. **出错**：红字只用于真的出错；「今天已经过完了」这类状态说明用普通提示。
7. **网页**：内容最宽 560，居中，像一张纸。网页用单页模式（`app.json` 的 `web.output: "single"`），不在服务器上先渲染，这样深色模式不会出现浅色标题栏。
8. **改动画值**用 `.set()`，不直接给 `.value` 赋值（React 编译器的检查要求）。
9. **网页上的动画**：Reanimated 4 网页版的自定义入场动画（`withInitialValues`）结束后会把元素钉成绝对定位，整页叠在一起，所以起始值一律经 `from()` 设，网页用默认值；网页上翻页不加退场动画（退场的元素会盖在新的一屏上）。

## 交互

调研依据：知识库 `成长导师/调研/reports/交互设计调研.md`；逐屏评审：同目录 `Fable评审-第2轮.md`、`Fable评审-第3轮.md`。

**导航**：底部浮动玻璃标签栏，三个标签「今天 / 本周 / 我」，选中的那块底在标签之间滑动（240ms 定时，不用弹簧），切标签时新页淡入；标签栏后面垫一层渐隐，内容滑到下面不透出半截字。报电量是从底部弹出的面板（透明弹层，后面看得见今天）；晚间对账和复盘是全屏流程；设置、数据从「我」推进去，带返回。从提醒直接点进 `/energy`、`/checkin` 时，下面也会先垫一层标签页（`unstable_settings.initialRouteName`）。

**今天**：顶上日期眉标、问候、一句「今天还有 3 件事，23:30 收尾。」；主角是今天的弧（不装卡片）。电量瓷砖整块可点（再报电量），底下一排五格；「记了几晚」瓷砖底下七个点。白天复盘入口排在时间线后面，晚上排在前面。一屏最多一个实心按钮，按一天里的四个状态画：
- 白天还没报电量：「此刻」卡片 + 实心「下课了，报个电量」+ 淡色「提前对账」。
- 报过了：不催，只有一行淡色「电量变了，再报一次」；19:00 以后实心按钮换成「对个账」。
- 今天的安排走完了、还没对账：卡片换成「今天走完了」，「对个账」按钮就在卡片里。
- 对完账：卡片换成「今天收好了」+ 明天先做的那件事 + 晚安，下面只留一个淡色「再改一下今晚的对账」，不再显示瓷砖和时间线。

「此刻」卡片：第一行「现在」（全卡唯一的陶土色字）和时间段，第二行事情的名字（20/600），第三行还剩几分钟（64 号大数字，分钟变了旧数字上移淡出、新数字淡入），然后进度条，最后一行「然后 18:40 看书」。下面两块瓷砖（电量几格、晚间记录几天；今天过完又没报写「今天没报」）→ 复盘入口 → 时间线（只显示接下来，过去的折叠；时长写「45 分钟」不重复写时间段；「自由时间：……」只第一次写整句）。可以下拉刷新；每次回到这页都重新拿计划，刷新失败在顶上说一句「没连上，显示的是刚才的计划」，4 秒后收起。

**报电量**：一节电池，五格连在一起，格子里不写数字，只用鼠尾草绿；点一格或者横着滑（松手才算），从第 1 格依次亮到第 n 格，电池上方写「2 格 · 有点累」。选完立刻列出「帮你改了 N 处」（再换一格时旧结果变淡留在原地，新的回来再换，面板不塌），一行一句话：「看书　45 分 → 10 分（保底）」（原来的划掉、灰色，新的加粗），新加的用绿色，今晚不排了的用灰色，一行接一行进场；没改就写「今晚不用动，照原来的来」。今晚完整的安排默认收起。点「就这样」确认后面板收起。断网时说「没连上」，电池熄掉，给「再试一次」。面板开的时候轻触一次；点遮罩、点关闭、按住把手或标题那一行往下拉都能关，拉的时候遮罩跟着变淡。

**晚间对账**：一屏一问。问题在上，三个大选项贴在底部按钮上方（做了 ● / 做了保底 ◐ / 今天没做 ○），点完停 0.3 秒自动翻页（开着读屏时不自动翻）；往前翻新的一屏从右边进，往回翻从左边进。项目再问一句和预想比；然后是「想说点什么」和「明天最想先做的一件事」。顶部是进度条（300ms）；第一屏左上角关闭、右上角「一句话说完」药丸，往后左上角回上一步、右上角关闭（和复盘一样）。保底的事说明换成「做满了标准版 / 按今晚的计划做了」；「昨晚定的一件事」只有做了和没做。「先不记这件」「跳过」「不写，下一步」都是灰字。完成页：月亮淡入（不回弹），原样引用你写的那句话，7 个点是这 7 天哪晚记了；填了「明天的一件事」就把它念回来；「晚安」用浅底按钮，夜里这一屏不放最亮的实心条。不做连胜，不做惩罚。

**本周**：记了几晚（大号 N / 7 加 7 格，哪晚记了哪格亮，下面标星期几；一晚都没记时换成一句「这周还没有记录」）→ 习惯（每个习惯一行七个它自己的记号：做了实心、保底半满、没做空心、那晚没对账一个小点；上面一排星期几对齐；图例写「做了 / 保底 / 没做 / 没记」）；今天那格还没记时只描边→ 每个项目一句话「多半和预想差不多」加一条三段比例条 → 复盘入口。

**我**：顶上一行真实的小结（「07:30 起 · 2 门课 · 2 个习惯」），下面「作息和习惯 / 课表和项目 / 提醒」分别进设置的那一段（`/settings?part=routine|classes|reminders`），再下面是我的数据和隐私说明（只读全文，`/privacy`）。

**深度长谈**（`/deep-talk`）：和对账一样的全屏、一屏一问、顶部进度条。对账完成页「晚安」上面一张邀请卡（第 N 次长谈 · 约 10 分钟，「现在聊 / 明天再说」）。打分是每项 11 个点（0–10，旁边写「6 分」），「关系」可以跳过；开放题答完，输入框下面淡入导师的一句；追问是三颗药丸，最多补两句；能量一屏列出所有习惯、课、项目，每行一个能量选择。第 4 次：三个版本各一屏 → 等智囊团（骨架 + 「今晚先到这」，没开起来给「再试一次」）→ 每个视角一张卡，卡里三个版本分开写「看到 / 最大的未知 / 一个月能做的试验」，不排名 → 四项打分 → 选一个或先不选 → 一张一张确认使命、目标、原型习惯、明天的一件事。每次聊完的小结原样引用你说的话。「我」页最上面是「我的方向」卡（使命一句、最多 3 个目标、接着聊 / 选一个版本 / 重新聊一次）；时间线上长谈来的习惯写「为了：…」。

**设置**：有改动时底部滑上来一条「保存」，存的结果（成功或为什么没存上）写在这条栏里按钮上方，成功时按钮变「存好了」停 1.2 秒再收；没保存就返回会先问一句；删除一个习惯、一节课或一个项目后，底部给几秒「撤销」。

**动效**：按下时缩到 0.97，弹簧回弹；页面错峰入场 320ms、每个晚 30ms、最多错开 5 个、位移 12，整屏 450ms 内落定；时间线的行不单独入场，展开收起时平滑挪位；面板开用 iOS 系统面板的曲线 380ms（不冲过头），关 220ms 先慢后快。系统开了「减少动态效果」时，reanimated 会自动跳过动画。

**触感**：选了一个选项、滑过一格电池（selection）；面板弹出（轻触）；确认计划和完成对账（success）。网页上没有触感。

**第一次打开**：欢迎页 → 隐私（三行要点 + 看完整说明 + 国家 + 年满 18 岁）→ 三四个问题 → 最后一屏起床、上床用时间选择器，一个习惯，按钮固定在底部。启动页跟系统深色模式走。

**加载和出错**：读数据时用骨架屏（形状和真内容对上），不用一行「正在加载」。没连上时整页换成 `ErrorState`；`api.ts` 的 `say(e)` 统一出错说明：后端说的话（比如「请点按钮补上」）原样给人看，断网这类原始报错只说「没连上」。
