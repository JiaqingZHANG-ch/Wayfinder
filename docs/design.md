# Wayfinder 界面设计规范：黏土小镇

Wayfinder 每天陪你排计划、晚上对账、每周复盘。它不是效率工具，也不是监工：不打分、不催、没有连胜，不用刺眼的红色，文案短、像人说话。

2026-11-21 起视觉方向是「黏土小镇」：一个穿黄雨衣的黏土小人站在小镇舞台上，陪你过今天。规格小样在本机 `.oil-ui/redesign2/explore/A-clay-town-v4.html`（不进仓库）。

## 材质只有两种说法

1. **黏土 = 图片**：小人、舞台场景、石子、夜豆、印章、电池、事件图标，全是 `mobile/assets/images/clay/` 里的 webp（同一张母版渲染：哑光、左上来光）。代码不画黏土：不叠纹理、不加内阴影、不画高光。素材只许非商用，上架前要重新出图（见同目录 `LICENSE-NOTE.md`）。
2. **控件 = 平色块**：卡片、按钮、标签栏、气泡、托盘格、阶梯。不描边，不叠模糊投影；厚度只有一种做法：实色底边 `0 4px 0 <底边色>`（RN 的 `boxShadow`）。主色控件用 `primaryEdge`，其余用 `cardEdge`；卡片多一道内高光（`c.clay`）。按下时底边收到 0、整体下移 4px。

输入框是唯一保留描边的东西（表单要看得出边界）。

## 令牌（`mobile/src/theme.ts`）

页面里不直接写颜色和数字，都从 `theme.ts` 拿：`useColors()` 给当前配色（白天跟随系统；21:00–6:00 或系统深色时用夜里那套），`space`、`radius`、`type` 是固定值。

| 令牌 | 白天 | 夜里 | 用途 |
|---|---|---|---|
| `bg` | `#F8EEDD` | `#191C28` | 页面底（奶油 / 石板） |
| `surface` | `#FFFAF1` | `#252A3A` | 卡片、气泡、次要按钮 |
| `surface2` | `#F3E6CF` | `#1F2331` | 次级面：输入框、「我」页顶条 |
| `tint` | `#FCE6BD` | `#4A3A3E` | 被改动的行、选中的浅主色底 |
| `ink` / `ink2` | `#2E2216` / `#6A5038` | `#FBF3E4` / `#CBD1E0` | 正文 / 次级字 |
| `primary` / `primaryEdge` | `#EBAA3C` / `#A3631A` | `#F2B64C` / `#B9761F` | 雨衣黄（只做填充）/ 它的底边 |
| `onPrimary` / `primaryInk` | `#2A1606` / `#8A4B0B` | `#2A1606` / `#FFC766` | 主色上的字 / 主色的字（大数字） |
| `done` / `mark` | `#3F8A64` / `#8E6E4C` | `#7FD1A6` / `#9AA3BF` | 做了 / 没做、没记的记号 |
| `line` / `cardEdge` | `#E7D8BF` / `#E2CFAE` | `#343A4E` / `#6B7493` | 分隔线 / 卡片底边 |
| `stage` | `#F7ECD9` | `#1B2033` | 舞台图没盖到的天 |

对比度：文字 ≥ 4.5:1，非文字（记号、控件边界）≥ 3:1。每对的实测值写在 `theme.ts` 注释里，改色后要重新量。

- 间距 `space`：4 / 8 / 12 / 16 / 24 / 32。
- 圆角 `radius` 只有三档：`card` 20、`btn` 14、`in` 12（加全圆 `pill`）。
- 字体：数字和英文用 Nunito，中文用系统字体（不打包中文字体）。字重分三层：Nunito 900（`hero` 60、`big` 48，一屏最多一个 hero）/ 800（`stat`）/ 700（`num`：时间、计数）；中文 700（`display` 页标题）/ 600（`title`、按钮）/ 500（`label` 行标题、气泡）/ 400（`body`、`small` 正文和副行）。
- 间隔号「·」每屏最多一处，能用空格、逗号或换行的就不用。

## 舞台和小人（`mobile/src/components/clay.tsx`）

- `Stage`：390×300 画布按屏宽等比缩放。白天、夜里两张场景交叉淡入（只看钟点，系统深色时中午还是白天的小镇）；路上的灰石子一颗一件还没做的事，做完一件淡出一颗。小人脚下只有 `fig-shadow` 接触阴影，不放石子。
- `Figure`：影子、身体、头、表情、闭眼分层叠放。白天、夜里、收尾都是同一套母版图，夜里整个人压暗一档（`filter: brightness`）。表情跟电量 1–5，1 格坐下打哈欠。常驻呼吸（4 秒）和眨眼（120ms）；「减少动态效果」打开或页面失焦时停掉。点小人 = 打开电量阶梯。
- `Bubble`：导师的一句话，平色块 + 底边，至少 44 高、最多两行；问了话就能点（白天开阶梯，晚上去对账）。
- `Mascot`：舞台外的小人（同一套分层图等比缩小）：出错页坐着歇会儿，同意页站着，本周顶上 120 高的小镇一角里走在路上。欢迎页用整个舞台。
- 「我」页的小人表情跟今天报的电量，没报和今天页一样是微笑。

## 报电量阶梯

舞台右侧一节黏土电池。点一下展开 5 级阶梯（1 只想躺着、2 有点累、3 正常、4 不错、5 很有劲），阶梯开着时气泡收起、舞台蒙一层；按住上下拖按档吸附，每过一档震一下，小人跟着换表情；位移 < 8px 不算提交，松手或点一级才算报了。报上以后重排计划，「接下来」里被改的行换 `tint` 底，副行写「10 分钟」加划掉的原时长。原来的 `/energy` 面板保留作兜底入口。

## 今天

舞台 → 「现在 高数」+「还剩 N 分钟」大数字（满 60 分钟写「1 小时 41 分」；只有正事当主角，吃饭、路上、自由时间不当；只剩生活块时不报数字，写「正事都做完了，歇会儿。」）→「接下来」列表（正事一行：时间、黏土图标、标题，副行只写时长或番茄；主角那件是一块卡片底；生活块是 13 号淡字、没有图标，连着的并成一行）→ 主按钮固定在标签栏上方，不跟着滚：白天「报个电量」/「再报一次」（阶梯开着是「就这样」），19:00 以后或正事都做完「对个账」，收好了就不放。

## 对账和收尾（`mobile/src/app/checkin.tsx`）

一律用夜里配色。顶上托盘格一件一格，点回去能改；中间一张大卡：事件图标、名字、几点开始多久；下面三个答案（做了 / 做了保底 / 今天没做）同色同重，只靠左边的记号区分（`done` 绿实心 / 绿半满 / `mark` 空心，和本周同一套），选了盖一个黏土章，停一下自动翻（开着读屏不自动翻）。项目做了再问一句和预想比。白天被挪走的事不进对账。

对完是收尾：夜里的舞台上小人坐下打哈欠，「今天收住了。」，没排上的事说一句，今天的账一件一块（点了回去改），三个可不填的输入框，按钮「晚安」固定在底部。没连上整页换 `ErrorState`。

## 本周和我

- 本周：顶上 120 高的小镇一角；只有记号表一张卡（不放图例），一整行都没记时只画今天那一格：第一行是这 7 晚哪几晚记了（夜豆；今天还没记是空圈，那晚没记是短线），下面每个习惯一行（做了实心、保底半满、没做空心、没记短线）；每个项目的估时对比用三堆石子；复盘入口在最上面。
- 我：顶条上站着小人，下面我的方向、长谈进度和主按钮、我的记号（每个习惯和项目一个黏土图标）、设置和隐私数据入口。读的时候放骨架；全没拿到换 `ErrorState`，拿到一部分顶上说一句。

## 组件和规则

页面只拼 `mobile/src/components/ui.tsx` 的件：`Screen`（`footer` 是固定在底部的主按钮）、`Card`、`Button`（primary / secondary / quiet / neutral / quietDanger / danger）、`Chip`、`ListRow`、`Field`、`Notice`、`CrisisCard`、`ErrorState`、`Header`、文字件。底部标签栏在 `app/(tabs)/_layout.tsx`：平色块，选中那块浅主色底带主色底边，在标签之间滑动，直接打开某个标签时直接落位。动效和触感在 `components/motion.tsx`。设置、长谈和旧时间线里还在用几何记号 `Glyph`（`components/art.tsx`）。

1. 可点区域至少 44pt；读屏用 `accessibilityLabel`，单选 `radio`、多选 `checkbox`。
2. 危机提示用平静的普通卡片，不用红色、不弹窗；红字只用于真的出错。
3. 读数据用骨架屏；没连上整页换 `ErrorState`，原始报错不给人看。
4. 网页：内容最宽 560 居中；单页模式（`web.output: "single"`）。
5. 改动画值用 `.set()`；网页上入场动画的起始值经 `from()` 设，翻页不加退场动画。
